# Product

## Register

product

## Users

Oryven is for people managing personal tasks and lightweight projects in a local-first Windows desktop app. They use it during focused work sessions to capture tasks quickly, scan priorities, organize work by project or date, and move between task views without losing context.

## Product Purpose

Oryven gives the same task database several practical lenses: list, kanban, calendar, table, and related planning views. Success means users can understand what needs attention, change structure quickly, and trust that local task data stays preserved across app updates.

## Brand Personality

Calm, precise, and lightweight. The interface should feel quiet and capable rather than decorative, with visual signals doing useful work for priority, project, due date, and completion state.

## Anti-references

Avoid marketing-style productivity dashboards, oversized cards, heavy shadows, ornamental gradients, gamified task boards, and bright inactive states. Avoid interfaces that look like generic SaaS templates rather than a focused desktop tool.

## Design Principles

- Keep the task in focus: controls and chrome should support scanning and acting, not compete with the data.
- Show, don't tell: use restrained color, hierarchy, and layout rhythm as state signals instead of explanatory copy.
- Preserve continuity: switching views should reframe the same task set without surprising data changes.
- Earn density: compact surfaces are acceptable when alignment, spacing, and touch/keyboard affordances remain clear.
- Respect local trust: upgrades, state preservation, and predictable Windows behavior matter as much as visual polish.

## Accessibility & Inclusion

Target WCAG AA for contrast and keyboard access. Interactive task surfaces should have visible focus states, semantic controls, labels that communicate the action, and reduced-motion-compatible transitions.
